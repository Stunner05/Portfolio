 Project Overview

This is my developer portfolio, built with Next.js and TypeScript.
It showcases my projects, skills, and background while dynamically fetching data from a Supabase + Prisma backend.

Tech Stack

Frontend:

Next.js 14 (App Router)

TypeScript

Tailwind CSS

ShadCN UI Components

Backend:

Prisma ORM

Supabase PostgreSQL Database

API Routes (Next.js Server Actions)

Deployment:

Vercel (Frontend + Serverless Functions)

Supabase (Database Hosting)
